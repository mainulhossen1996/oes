# Orin Engineering & Supplies

Next.js 14 (App Router) + Tailwind CSS landing page.

## Run
```
npm install
npm run dev     # http://localhost:3000
```

## Edit your details
Phone, WhatsApp number, email and address live in `lib/site.js`.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New > Project, import the repo, and click Deploy.
No environment variables are needed.
